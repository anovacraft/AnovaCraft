# Changelog

## 0.1.0 (first public release)

The first public release of AnovaCraft: a desktop application for
statistical analysis, design of experiments and predictive modelling, with
linked brushing across every plot and data view.

- Analyses under Describe, Compare, Model, Multivariate, Design, Quality,
  Reliability, Series and Signals, and Visualize; [FEATURES.md](FEATURES.md)
  lists them all.
- Sample data for every analysis (File ▸ Open sample data).
- Projects (`.acraft`) that reopen every report exactly; import of CSV, TSV,
  JSON and spreadsheet workbooks; export to CSV, TSV, JSON and `.xlsx`.
- Rhai scripting, formula columns, recorded actions and the headless
  `anovacraft-run` runner.
- Quick Guide and Reference Manual built into the app (Help menu).
- Accuracy checked against the NIST Statistical Reference Datasets and other
  independent references ([docs/validation.md](docs/validation.md)).

Downloads: a universal macOS app (Apple silicon and Intel, macOS 11 or
later) and a 64-bit Windows app. Neither is code-signed yet; see
[README.md](README.md#installing) for how to open them the first time.
